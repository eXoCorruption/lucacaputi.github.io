Ich bin momentan in der Ausbildung zum Applikationsentwickler. Die Schule absolviere ich in Zürich bei der WISS.

Während sich andere mit Spielzeug beschäftigt haben, habe ich alte Geräte auseinandergenommen und kleine Projekte ausgetüftelt. Diese Neugier war nie nur ein Hobby, sondern der Beginn einer Leidenschaft, die mich bis heute antreibt.

Ein Meilenstein war der Bau meines ersten eigenen Computers: die Auswahl der Komponenten, das Zusammensetzen der Hardware und das Optimieren der Konfiguration haben mir gezeigt, wie viel strukturiertes Denken in der Technik steckt.

Meine Motivation kommt aus dem Drang, Neues zu lernen und Probleme kreativ zu lösen. Technik ist für mich kein Arbeitsfeld, sondern eine Welt, in der ich täglich entdecke, wie viel Potenzial in scheinbar einfachen Systemen steckt.

Plattformen

Drei Welten, ein Handwerk.

Ich entwickle nicht nur fürs Web — mobile Entwicklung gehört genauso dazu.

Web-Entwicklung

Statische Seiten und kleine Web-Apps von Grund auf: sauberes HTML, modernes CSS und JavaScript ohne unnötigen Ballast. Deployment über GitHub Pages, Versionierung mit Git.

  • HTML & CSS
  • JavaScript
  • Responsive Design
  • GitHub Pages
  • REST APIs

Android-Entwicklung

Erfahrung mit nativer Android-Entwicklung in Android Studio: Aufbau von Activities und Layouts, Umgang mit dem Lifecycle, Anbindung von APIs und das Ausrollen auf echte Geräte. Java bringe ich aus meinen Minecraft-Projekten mit.

  • Android Studio
  • Kotlin
  • Java
  • Material Design
  • Gradle

iOS-Entwicklung

Erste Apps mit Swift und SwiftUI in Xcode: deklarative Views, Navigation, State-Handling und die Human Interface Guidelines von Apple. Mich reizt besonders, wie stark Design und Technik auf iOS zusammenspielen.

  • Swift
  • SwiftUI
  • Xcode
  • Human Interface Guidelines
  • TestFlight
